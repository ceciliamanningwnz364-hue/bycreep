# bycreep

Тяжёлое приложение для тренировок, прогресса и питания. Чёрный интерфейс, белая типографика, красный акцент. Без подписок, аккаунтов и облака — все данные остаются на iPhone.

Оптимизировано под **iPhone 14 Pro** (iOS 17+), но запускается на всех iPhone с iOS 17.

## Что внутри

- **Сегодня** — программа дня, недельный стрип, быстрый старт, последние тренировки, карточка питания.
- **Зал** — ручные программы, редактор дней/упражнений/подходов, генератор тяжёлого сплита по параметрам.
- **Тренировка** — подходы, вес, повторения, отдых с таймером, пауза/продолжение, завершение или удаление.
- **Прогресс** — месячные фото с ленивой загрузкой, сравнение двух фото со слайдером, вес и обхваты, график, история тренировок.
- **Питание** — калории, белки/углеводы/жиры, вода, приёмы пищи, офлайн-база продуктов и ручное добавление.
- **Профиль** — параметры тела, цель, активность, опыт, расчёт нормы питания, пересборка программы.
- **Виджет** — чёрный фон, белые круги ПН–ВС, сегодняшний тренировочный день светится красным.

## Стек

- SwiftUI
- SwiftData
- WidgetKit
- XcodeGen (проект генерируется из `project.yml`)
- Без сторонних зависимостей

## Быстрый старт

Нужны macOS, Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
cd bycreep
xcodegen generate
open bycreep.xcodeproj
```

Дальше:

1. Выбери команду разработчика (Signing & Capabilities) для **обоих** таргетов: `bycreep` и `bycreepWidgetExtension`.
2. Проверь App Group `group.com.bycreep.app` в обоих таргетах. Если идентификатор уже занят, замени его в:
   - `bycreep/bycreep.entitlements`
   - `bycreepWidget/bycreepWidget.entitlements`
   - `Shared/BycreepShared.swift` (`appGroupID`)
3. При необходимости поменяй bundle ID: `com.bycreep.app` и `com.bycreep.app.widget`.
4. Выбери схему `bycreep`, устройство iPhone 14 Pro и нажми Run.

Если подпись не проходит, обнови provisioning profiles после добавления App Group.

## Виджет

1. Долгое нажатие на домашний экран → «+» → найди **bycreep**.
2. Добавь маленький или средний виджет.
3. Открой приложение хотя бы раз — виджет получит снимок недели.
4. После изменения активной программы или закрытия тренировки приложение само обновляет таймлайн (только если контент реально изменился).

Виджет не открывает SwiftData и не хранит фотографии. Он читает компактный JSON из App Group:

```swift
struct WidgetSnapshot {
    var trainingWeekdays: [Int]      // 1 = ПН ... 7 = ВС
    var completedDateKeys: [String]  // yyyy-MM-dd
    var programName: String?
    var updatedAt: Date
}
```

## Решения по производительности

- **SwiftData** с ленивыми `@Query` и выборками по датам; тяжёлые фото и изображения не попадают в базу.
- **Фото**: downsampling через ImageIO до 2400 px, JPEG 0.84, `NSCache` на 64 МБ, отдельные миниатюры для сетки.
- **График веса** рисуется через `Canvas`, без Swift Charts и лишних слоёв.
- **Таймер тренировки** восстанавливается из `activeStartedAt + durationSeconds`, ставится на паузу при уходе в фон и не считает время в фоне.
- **Незавершённая тренировка** доступна для продолжения в течение 7 дней — можно закрыть приложение на ночь и не потерять отмеченные подходы.
- **Виджет** использует крошечный JSON-снимок, а не контейнер SwiftData; `reloadTimelines` вызывается только при изменении содержимого.
- **Сегменты и навигация** не создают тяжёлых вложенных списков: карточки собираются из лёгких View и стабильных `id`.
- **Анимации** короткие и только на интерактивных элементах; фон — статичный градиент.
- Тёмная тема зафиксирована, лишние перерисовки цвета не происходят.

## Иконка

Иконка лежит в `bycreep/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` (1024×1024, PNG без альфа-канала — требование App Store).
Перегенерировать на Windows:

```powershell
powershell -ExecutionPolicy Bypass -File Tools/generate_icon.ps1
```

## Данные и приватность

- Нет сетевых запросов: база продуктов и расчёты локальные.
- Фото, замеры, питание и тренировки хранятся в SwiftData и Application Support.
- Для App Store добавлен `PrivacyInfo.xcprivacy` с причиной использования `UserDefaults` для App Group.
- Удаление фото удаляет и файл с диска.

## Ручная проверка после сборки

- [ ] Онбординг создаёт профиль, стартовый замер и программу.
- [ ] Тренировка: отметить подходы, дождаться таймера отдыха, свернуть и продолжить.
- [ ] Тренировка ставится на паузу при уходе в фон и не считает фоновое время.
- [ ] Редактор: максимум 7 дней, выбор занятого дня меняет дни недели местами, пустой день нельзя начать.
- [ ] Незавершённая тренировка возобновляется на следующий день и после перезапуска приложения.
- [ ] При запуске другого дня с незавершённой тренировкой приложение предлагает продолжить её или начать новую.
- [ ] Завершённая тренировка появляется в истории и отмечает день в виджете.
- [ ] Фото из галереи и камеры сохраняются, сравнение работает.
- [ ] Замер обновляет вес в профиле и на графике.
- [ ] Питание: база, ручное добавление, вода, удаление записи.
- [ ] Профиль: изменение веса добавляет/обновляет замер, норма пересчитывается.
- [ ] Виджет: маленький и средний размеры, красное свечение в тренировочный день.

## Ограничения

- Нет синхронизации с iCloud, HealthKit и Apple Watch.
- База продуктов приблизительная и предназначена для быстрого дневника, а не для медицинских расчётов.
- Генератор выдаёт ориентир по стартовым весам; техника и самочувствие важнее цифр.
